# 🍕 LA PIAZZA

## Présentation du projet

La Piazza est un site web pour un restaurant italien spécialisé dans les pizzas.

Ce projet a pour objectif de présenter le restaurant, son menu et de permettre aux visiteurs de consulter les informations et de réserver une table.

## Pages du site

Le site contient 4 pages principales :

- Accueil : présentation du restaurant et de ses spécialités.
- Notre Menu : présentation des pizzas et leurs prix.
- Réservation : formulaire de réservation d'une table.
- Contact : coordonnées et formulaire de contact.

## Technologies utilisées

- HTML5
- CSS(3 version : v1_traditionel/v2_felexbox/v3_grid)
- JavaScript 
- Git et GitHub pour la gestion du projet.

## Organisation du projet

Le projet est réalisé en groupe de 4 étudiants.

Chaque membre travaille sur une page dans une branche indépendante.

## Installation

1. Cloner le repository.
2. Ouvrir le dossier du projet avec Visual Studio Code.
3. Ouvrir le fichier `index.html` dans un navigateur.
